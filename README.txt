HOMEXA SOLUTION WEBSITE

Open index.html in any browser to preview. Upload this whole folder to your hosting.

images/  put your photos here (replace a file with the same name, or add new ones)
video/   put your videos here (MP4 works best)

To change things:
- Facebook / Instagram: open index.html, search for "YOUR-PAGE" and "YOUR-HANDLE", replace with your real links.
- WhatsApp number: search for 923008537376 in index.html and js/main.js.
- New photo in the gallery: copy one <button><img ...></button> line in the gallery section and change the file name.
- New video: change video/construction-timelapse.mp4 in the video section to your file name.
